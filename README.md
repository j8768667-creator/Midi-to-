# Riffler Composer

Ready-to-publish GitHub Pages site.

## iPad upload with Working Copy

1. Unzip this folder in Files.
2. Open Working Copy.
3. Open or create your GitHub repo.
4. Import these files into the root of the repo:
   - index.html
   - manifest.webmanifest
   - sw.js
   - README.md
5. Commit.
6. Push.
7. On GitHub in Safari, open repo Settings → Pages.
8. Set Source to Deploy from a branch.
9. Set Branch to main and Folder to / root.
10. Save.

Your app will be available at the GitHub Pages URL shown there.
