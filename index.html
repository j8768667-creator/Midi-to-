MIDI → .riffle

Converts a standard MIDI file into a RifflerFLOW-compatible .riffle file. Runs entirely in your browser — nothing is uploaded anywhere.

input
Any real .riffle file. Its header and chord-name fields (not yet fully decoded) are copied through untouched — only tempo, bar count, and the note data are replaced with your MIDI's.
Use this if your MIDI came from a live-recorded MIDI-out stream rather than a true export — those often carry a placeholder tempo instead of the real one.
Default 16 = sixteenth-note grid in 4/4. Change this if your MIDI's note grid doesn't divide evenly into 16.

what's verified vs. still a placeholder
  • Pitch (riffle note = MIDI note − 12) — confirmed exactly against a 64-note reference file
  • Duration (fixed grid, quarter note = 1000 ticks, independent of tempo) — confirmed
  • Tempo (header field = BPM × 100) — confirmed
  • Bar count and its header placeholders — confirmed
  • Chord-name labels shown in the app — copied from the template, so they may not match your converted notes
  • A possible second "layer" some .riffle files carry (e.g. a chord-strum accompaniment alongside the melodic line) — not reproduced, since a single MIDI take doesn't contain it
