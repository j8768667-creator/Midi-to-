MIDI → Riffler .riffle

Browser-only converter for GitHub Pages. It keeps a valid Riffler file as the structural template, but converts MIDI timing, duration, velocity and note events into the three observed musical planes instead of simply writing a list of pitches.

1. Files

Choose a .riffle that already opens in Riffler. The converter preserves the file's non-musical structure and uses its 512-slot musical layout as the target pattern.
Standard format 0/1 MIDI is supported. Tempo changes and note durations are retained.
