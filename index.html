MIDI → .riffle Converter

iPad-friendly converter. Uses a valid .riffle as a structural template: instead of guessing where notes live, it learns the template's own note-slot layout (pitch / duration / gate tables kept in lockstep) and refills it with your MIDI, so the block structure Riffler expects stays intact.

A known-good template is built in, so this step is optional. Its only job now is to donate a valid header/skeleton — the converter detects its repeating note-block pattern and re-tiles it to fit however many notes your MIDI actually has, up to the format's ~500-note-slot ceiling, so you're no longer limited to that one file's original length. Upload your own only if you want a different starting key/instrument label.
Best results: a simple melody or chordal MIDI. If you cannot upload MIDI, paste the event dump below instead.
