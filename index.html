Riffler App

Single-file iPad-friendly converter for simple MIDI files or pasted MIDI event dumps. Upload this file as index.html to GitHub Pages.

How to use on iPad

Tap Choose File to select a MIDI from Files, or paste an event dump. Then tap Download .riffle. The exported file will appear in Downloads/Files and can be opened in Riffler.
